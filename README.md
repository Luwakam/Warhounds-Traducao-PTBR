# Warhounds-Traducao-PTBR
Tradução Completa sem revisão do jogo Warhounds. (TRADUÇÃO FEITA POR IA)


Como esse é um jogo que eu pretendo jogar futuramente, eu planejo revisar e corrigir os erros logo mais! Mas por enquanto a tradução esta concluída até eu arrumar tempo pra corrigir. 
Outra coisa é que não consegui fazer o til (~) funcionar dentro do jogo, então palavras com esse sinal aparecerão sem ele!


Cole o arquivo "Spanish" para dentro dessa pasta "Localizations" e substitua o original.
.../Warhounds\Warhounds_Data\StreamingAssets\Localizations

Dentro do jogo altere o idioma para espanhol/Spanish e se divirta!
